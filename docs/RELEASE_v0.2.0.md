# v0.2.0 — Local YOLOv8 + EfficientNetV2 bird recognition

原项目的图片识别依赖缺失的外部模型服务，无法在本地返回真实推理。新增 `bird_service/` 后，可用 YOLOv8 检测鸟框、OpenCV 裁剪、EfficientNetV2-S 分类，直接接入现有登录后的 Java / Vue 上传流程，无需云存储。

包括专用分类器训练、验证集选模、测试评测、来源组与像素泄漏检查、未知类别拒识、模型来源信息和公开样图。

本机验证：8 项算法/API 测试；12 组现有系统集成检查（以本地真实识别替换未配置服务检查）；Java 打包、Vue 生产构建、浏览器真实上传、公开图片推理、空白图负例、一轮合成数据训练/保存/回读/评测。

原模型与权重没有恢复。现成可运行模式是上游 COCO / ImageNet 预训练流程演示，没有完成目标鸟类专用模型的真实数据训练与准确率评测。群体图候选框数不是人工标注计数精度。新增算法模块采用 AGPL-3.0；原归档代码和素材的许可边界保持各自说明。
